# Deploy and Manage Apigee X: Challenge Lab

## Overview

In this challenge lab, you will configure and secure an **Apigee X evaluation org** for Cymbal Shops. You will:

1. Modify environments and environment groups.
2. Set up access routing for internet access.
3. Create and activate a NAT address for the runtime instance.
4. Create and attach a Cloud Armor security policy.
5. Attach the staging environment to the runtime instance.


## **Task 1: Modify Environments & Environment Groups**

### Objective

Add a new environment (`staging`) and environment group (`staging-group`) to the Apigee X org.

### Steps

1. **Access Apigee UI**:
   - Go to [Apigee Console](https://apigee.google.com/).
2. **Create Environment**:
   - Navigate to **Admin > Environments**.
   - Click **+ Environment**.
   - Name: `staging`.
   - Proxy Type: **Programmable**.
   - Click **Create**.
3. **Create Environment Group**:
   - Navigate to **Admin > Environment Groups**.
   - Click **+ Environment Group**.
   - Name: `staging-group`.
   - Add Hostname (keep default).
   - Attach the `staging` environment.
   - Click **Save**.

## **Task 2: Set Up Access Routing**

### Objective

Enable internet access for the Apigee X org using the provisioning wizard.

### Steps

1. **Access Apigee Provisioning**:
   - Go to [Apigee Provisioning](https://console.cloud.google.com/apigee/provisioning).
2. **Wait for Org Creation**:
   - Ensure **Step 3 (Org Creation)** is complete.
3. **Complete Step 4: Access Routing**:
   - Proceed to **Step 4: Access Routing**.
   - Subnetwork: Use `api-subnet`.
   - DNS: Use the default **nip.io** wildcard DNS.
   - Click **Complete**.

## **Task 3: Create and Activate a NAT Address**

### Objective

Create a NAT IP address (`apigee-nat-ip`) for the runtime instance.

### Steps

1. **Get Access Token**:

   ```bash
   gcloud auth print-access-token
   ```

2. **Create NAT IP**:

   ```bash
   curl -X POST -H "Authorization: Bearer $(gcloud auth print-access-token)" \
   -H "Content-Type: application/json" \
   -d '{
         "name": "apigee-nat-ip"
       }' \
   "https://apigee.googleapis.com/v1/organizations/YOUR_ORG/instances/eval-instance/natAddresses"
   ```

3. **Activate NAT IP**:

   ```bash
   curl -X POST -H "Authorization: Bearer $(gcloud auth print-access-token)" \
   -H "Content-Type: application/json" \
   -d '{
         "state": "ACTIVE"
       }' \
   "https://apigee.googleapis.com/v1/organizations/YOUR_ORG/instances/eval-instance/natAddresses/apigee-nat-ip"
   ```

## **Task 4: Create and Attach Cloud Armor Policy**

### Objective

Create a Cloud Armor policy (`protect-apigee`) to block remote code execution attacks.

### Steps

1. **Create Cloud Armor Policy**:

   ```bash
   gcloud compute security-policies create protect-apigee \
     --description "Block remote code execution"
   ```

2. **Add Rule to Block Remote Code Execution**:

   ```bash
   gcloud compute security-policies rules create 1000 \
     --security-policy protect-apigee \
     --expression "evaluatePreconfiguredExpr('rce-stable')" \
     --action "deny-403"
   ```

3. **Attach Policy to Load Balancer**:

   ```bash
   gcloud compute backend-services update apigee-proxy-backend \
     --security-policy protect-apigee \
     --global
   ```

---

## **Task 5: Attach Staging Environment to Runtime Instance**

### Objective

Attach the `staging` environment to the runtime instance.

### Steps

1. **Get Access Token**:

   ```bash
   gcloud auth print-access-token
   ```

2. **Attach Environment**:

   ```bash
   curl -X POST -H "Authorization: Bearer $(gcloud auth print-access-token)" \
   -H "Content-Type: application/json" \
   -d '{
         "environment": "staging"
       }' \
   "https://apigee.googleapis.com/v1/organizations/YOUR_ORG/instances/eval-instance/attachments"
   ```

## **Key Notes**

- **Default Region/Zone**: Use `us-west1` (region) or `us-west1-a` (zone) unless specified.
- **Resource Naming**: Follow the `team-resource` format (e.g., `api-portal`).
- **Cost-Effective Sizing**: Use `f1-micro` for small VMs and `n1-standard-1` for other applications.

## **Troubleshooting**

- **Provisioning Delays**: Wait for Apigee org provisioning to complete before proceeding.
- **Cloud Armor Propagation**: Rules may take a few minutes to propagate.
- **API Errors**: Verify access tokens and ensure correct API endpoints.
