# Migrate a MySQL Database to Google Cloud SQL: Challenge Lab

To migrate the MySQL database to Google Cloud SQL and reconfigure WordPress, follow these steps using the command line:

**Task 1: Create a Cloud SQL Instance**

```bash
gcloud sql instances create wp-cloudsql \
    --database-version=MYSQL_8_0 \
    --region=us-west1 \
    --tier=db-n1-standard-1 \
    --root-password='Password1*'
```

---

**Task 2: Configure the Database and User**

1. Create the `wordpress` database:

```bash
gcloud sql databases create wordpress --instance=wp-cloudsql
```

2. Create the `blogadmin` user:

```bash
gcloud sql users create blogadmin \
    --host=% \
    --instance=wp-cloudsql \
    --password='Password1*'
```

---

**Task 3: Database Dump and Import**

1. **Authorize Blog Instance IP:**

```bash
BLOG_IP=$(gcloud compute instances describe blog --zone=us-west1-a --format='get(networkInterfaces[0].accessConfigs[0].natIP)')
gcloud sql instances patch wp-cloudsql --authorized-networks=$BLOG_IP/32
```

2. **Export Local Database:**

```bash
gcloud compute ssh blog --zone=us-west1-a --command "mysqldump -u blogadmin -p'Password1*' wordpress > wordpress.sql"
```

3. **Import to Cloud SQL:**

```bash
CLOUDSQL_IP=$(gcloud sql instances describe wp-cloudsql --format='get(ipAddresses[0].ipAddress)')
gcloud compute ssh blog --zone=us-west1-a --command "mysql -h $CLOUDSQL_IP -u blogadmin -p'Password1*' wordpress < wordpress.sql"
```

---

**Task 4: Reconfigure WordPress**

1. **Update Database Host in `wp-config.php`:**

```bash
gcloud compute ssh blog --zone=us-west1-a --command "sudo sed -i \"s/'DB_HOST', 'localhost'/'DB_HOST', '$CLOUDSQL_IP'/\" /var/www/html/wordpress/wp-config.php"
```

2. **Restart Web Server (Apache):**

```bash
gcloud compute ssh blog --zone=us-west1-a --command "sudo systemctl restart apache2"
```

---

**Task 5: Validate**

1. **Get Blog Instance External IP:**

```bash
gcloud compute instances describe blog --zone=us-west1-a --format='get(networkInterfaces[0].accessConfigs[0].natIP)'
```

2. Visit the IP in a web browser to check if WordPress loads correctly.

**Troubleshooting Tips:**

- Test database connection from the blog instance:

  ```bash
  mysql -h $CLOUDSQL_IP -u blogadmin -p'Password1*' wordpress -e "SHOW TABLES;"
  ```

- Verify Cloud SQL user privileges and imported data.

---

This sequence creates the Cloud SQL instance, configures the database, migrates the data, updates WordPress configuration, and ensures the application connects to the new database.
