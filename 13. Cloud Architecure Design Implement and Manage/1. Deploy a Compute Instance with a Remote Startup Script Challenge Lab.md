# Deploy a Compute Instance with a Remote Startup Script: Challenge Lab

## Overview

In this challenge lab, you are given a scenario and a set of tasks. You will use the skills learned from the labs in the course to complete the tasks on your own. An automated scoring system will provide feedback on whether you have completed your tasks correctly.

## Challenge Scenario

You have been given the responsibility of managing the configuration of your organization's Google Cloud virtual machines. You want to make it easier to modify the startup scripts used to initialize a number of the compute instances. Instead of storing startup scripts directly in the instances' metadata, you have decided to store the scripts in a Cloud Storage bucket and then configure the virtual machines to point to the relevant script file in the bucket.

A basic bash script that installs the Apache web server software called `install-web.sh` has been provided for you as a sample startup script. You can find the startup script in a public Cloud Storage bucket at `gs://spls/gsp301/install-web.sh`.

## Tasks

### Task 1: Create a Storage Bucket

1. Open Google Cloud Shell.
2. Create a new storage bucket:

   ```bash
   gsutil mb gs://qwiklabs-gcp-03-4fd2e57fcfae
   ```

### Task 2: Create a VM Instance with a Remote Startup Script

1. Create a new VM instance and specify the startup script URL:

   ```bash
   gcloud compute instances create my-vm-instance \
       --zone=us-central1-c \
       --metadata=startup-script-url=gs://qwiklabs-gcp-03-4fd2e57fcfae/install-web.sh \
       --scopes=https://www.googleapis.com/auth/devstorage.read_only
   ```

### Task 3: Create a Firewall Rule to Allow Traffic (80/tcp)

1. Create a firewall rule to allow HTTP traffic:

   ```bash
   gcloud compute firewall-rules create allow-http \
       --allow tcp:80 \
       --source-ranges 0.0.0.0/0 \
       --target-tags http-server
   ```

2. Add the tag to the VM instance:

   ```bash
   gcloud compute instances add-tags my-vm-instance \
       --zone=us-central1-c \
       --tags=http-server
   ```

### Task 4: Test that the VM is Serving Web Content

1. Get the external IP address of your VM instance:

   ```bash
   gcloud compute instances list --filter="name=my-vm-instance" --format="get(networkInterfaces[0].accessConfigs[0].natIP)"
   ```

2. Open a web browser and navigate to `http://[EXTERNAL_IP]`. You should see the Apache default page.

## Tips and Tricks

- **Configure Instance Metadata**: Ensure the startup script URL is correctly set in the instance metadata.
- **Check Permissions**: Make sure the VM instance has the necessary permissions to read from the storage bucket.
- **Check Firewalls**: Verify that the firewall rule is correctly configured to allow HTTP traffic.
- **Check the URL and Address**: Ensure you are using the correct external IP address and HTTP protocol.
